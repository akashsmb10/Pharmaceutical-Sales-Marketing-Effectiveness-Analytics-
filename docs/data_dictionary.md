# Data dictionary — synthetic commercial analytics

## Scope and grain

All tables are synthetic/simulated and generated by `run.py` with seed `360`. IDs are artificial integers, territories are placeholders, and dollar values are illustrative. The model contains commercial-activity analogues only; it contains no protected health information, real prescriber data, or real sales data.

| Table | Grain | Primary key | Purpose |
|---|---|---|---|
| `territory` | one synthetic territory | `territory_id` | Territory lookup |
| `physician` | one synthetic physician | `physician_id` | Physician lookup and territory assignment |
| `campaign` | one synthetic campaign/channel | `campaign_id` | Campaign lookup |
| `prescription_month` | one physician-month, including zero volume | (`physician_id`, `month`) | Synthetic prescription, revenue, and target facts |
| `outreach` | zero or one campaign contact per physician-month | (`physician_id`, `month`) | Synthetic outreach and recorded response facts |

## Field definitions

### `territory`

| Field | Type | Key / rule | Definition |
|---|---|---|---|
| `territory_id` | integer | Primary key; 1–8 | Synthetic territory identifier |
| `territory_name` | text | Required | Placeholder display name, e.g. `Territory 1` |

### `physician`

| Field | Type | Key / rule | Definition |
|---|---|---|---|
| `physician_id` | integer | Primary key | Synthetic physician identifier |
| `territory_id` | integer | Foreign key to `territory` | Assigned synthetic territory |
| `specialty` | text | Required | Simulated specialty: Primary care, Endocrinology, or Internal medicine |

### `campaign`

| Field | Type | Key / rule | Definition |
|---|---|---|---|
| `campaign_id` | integer | Primary key | Synthetic campaign identifier |
| `campaign_name` | text | Required | Simulated campaign name |
| `channel` | text | Required | Simulated channel: Email, Webinar, or Field |

### `prescription_month`

| Field | Type | Key / rule | Definition |
|---|---|---|---|
| `physician_id` | integer | FK to `physician`; composite key | Synthetic physician identifier |
| `month` | text (`YYYY-MM`) | Composite key | Calendar month from `2025-01` through `2025-12` |
| `prescriptions` | integer | Non-negative | Simulated monthly prescription count; zero values are retained |
| `revenue_usd` | decimal | Non-negative | Illustrative simulated revenue calculated from prescriptions and a generated price; not real revenue |
| `target_rx` | integer | Positive | Simulated monthly prescription target; not stakeholder-approved target data |

### `outreach`

| Field | Type | Key / rule | Definition |
|---|---|---|---|
| `physician_id` | integer | FK to `physician`; composite key | Contacted synthetic physician |
| `month` | text (`YYYY-MM`) | Composite key | Month of the simulated contact |
| `campaign_id` | integer | FK to `campaign` | Simulated campaign/channel associated with the contact |
| `responded` | integer | `0` or `1` | Simulated recorded campaign response, not prescription conversion or clinical outcome |
| `cost_usd` | decimal | Non-negative | Illustrative simulated contact cost |

## Referential relationships and validation

- A territory can have many physicians.
- A physician can have many monthly prescription records and outreach records.
- A campaign can have many outreach records.
- `run.py` rejects duplicate physician IDs, duplicate physician-month facts, duplicate outreach physician-month records, missing values, orphan foreign keys, invalid response labels, negative values, and incomplete 12-month physician coverage.

## Important analytical limitations

- Outreach selection is non-random in the generator and depends partly on simulated underlying activity. Campaign-response differences are **not causal uplift estimates**.
- There is no product entity or product-level fact. Product analysis cannot honestly be claimed from this current model.
- The data has no real patient, physician, territory, client, market, or campaign meaning.
- Activity segments use the full observation year and are retrospective; they are not prospective targeting recommendations.
